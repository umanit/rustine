**Rustine** ouvre des merge requests GitLab qui corrigent **uniquement** les paquets Composer et Yarn touchés par une CVE
remontée par [Trivy](https://trivy.dev). Pas de mises à jour de confort, pas de bruit : un paquet a droit à une merge
request parce qu’il est vulnérable, et seuls les paquets vulnérables sont ciblés (pas de montée de version majeure, pas
de dépendance non concernée). La première tentative, un rafraîchissement du lockfile, résout la version la plus haute
que permet chaque plage déclarée : d’autres dépendances peuvent donc bouger au passage, et la description de la merge
request liste tous les paquets que le lockfile modifie.

> **Statut :** pré-version (`0.x`) : la CLI est complète et prête pour des projets pilotes ; attendez-vous à des ajustements.
